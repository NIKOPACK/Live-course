# Security policy

Please report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/NIKOPACK/livecourse/security/advisories/new). Do not open a public issue containing exploit details, credentials, or personal data.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Maintainers will assess the report and coordinate disclosure and remediation through the private advisory.

Security fixes are maintained on the `main` branch. Deployments should track current commits and keep provider credentials in environment variables or a secret manager, never in source control.
