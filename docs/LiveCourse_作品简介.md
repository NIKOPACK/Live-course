# LiveCourse 作品简介

> 开发以 [docs/spec/](spec/00-index.md) 为准。本文是对外叙事，不是工作规格。

**LiveCourse —— 面向真实课堂的多模态实时教学 Agent：让 AI 成为会教书的老师，而不是会说话的答疑工具。**

**项目名**：LiveCourse

**赛题**：AI 教育方向，用 Agent 重构「教—学—评—调」完整教学闭环。

**目标用户**：大中学生、语言学习者、职教培训者；教师保留控制权。

**核心问题**：现有 AI 教育多为「答疑式」——不备课、不追掌握、不记得学生、不对结果负责。

**方案**：一句话或上传课件即可备课，生成幻灯片、测验、白板、互动、PBL 多场景课程；AI 教师虚拟形象全双工实时授课，支持学生打断与节点恢复；检查点与证据台账判定掌握，并据此调整后续教学。基于 Next.js，浏览器/PostgreSQL 双存储。

**创新点**：①Agent 拥有完整教学过程而非被动问答；②证据闭环可追溯，低置信度评分可复核，调整有据可依；③实时语音+VRM 教师形象多模态同步；④PBL v2 四 Agent 闭环，熟练度由确定性代码计算；⑤可审计教学事件总线。

**开放价值**：MIT 开源、数据契约开放；共建学科 Skill；隐私优先，仓库不含真实学生数据。

**进展**：一期已落地——课程生成、四类场景与播放引擎、实时授课、证据台账、PBL v2 闭环、可视化编辑器、MP4 渲染均可运行，配测试与评测体系。路线图：多课时课程规划、BKT/FSRS 学情建模、课堂感知。
