# 用户旅程

唯一用户是**学习者**。唯一成功标准：说明要学什么之后，一位 Agent 老师把一堂课教完（讲过、回应过插话、检查过），并在以后仍能用合适的方法教这位学习者。

没有人类教师。没有改课、画布编辑、Agent 重做某一段、导出给老师审阅。

## 主路径

```
首页写主题 / 目标 + 可选上传 → 按一次「开始上课」
                                 → 自动进入生成预览
                                 → 按需逐题追问 → 按需范围勾选（都在预览页内、生成教案之前）
                                 → 生成教案 → 逐段生成 / 失败段单独重试
                                                                  → 显式「进入课堂」
                                                                  → 讲授 ┬─ 插话：先答，再回 resumeNode
                                                                         ├─ 检查：提交答案，留下唯一证据
                                                                         └─ 暂停 / 继续 / 重听已讲部分
                                                                  → completed → finalizing → 课后「再听」或「离开」
以后再来 ─┬─ 同一课程：同课程记忆 + 学习者记忆 → 明确选择继续 / 再听
          └─ 新课程：只用学习者记忆 → 按 J1 确认本课
```

## 每步交互契约

每一步都必须同时明确六项：**步骤 / 状态、用户输入方式、系统可见反馈、跳过或失败恢复、完成后的状态迁移、三层记忆读写**。以下记号固定为：`W` = `ClassroomWorkingMemory`（session），`C` = `CourseLearningMemory`（learner + course），`L` = `LearnerMemory`（learner-only）。普通 UI 草稿、上传缓存与设置配置不属于 W / C / L。

| 步骤 / 状态 | 用户输入方式 | 系统可见反馈 | 跳过或失败恢复 | 完成后的状态迁移 | W / C / L 读写 |
|---|---|---|---|---|---|
| J1.1 首页填写目标 | 在单一文本框键入主题或目标；移出目标框（blur）或在键盘提交时触发校验 | 空目标时主按钮保持禁用；目标框 touched / blur 或键盘提交尝试后显示行内必填提示，输入保留 | 目标不可跳过；页面错误不清空文本；不依赖点击 disabled 按钮触发提示 | 留在首页草稿态 | 只读 `L` 以准备减少重复追问；草稿不写 W / C / L |
| J1.2 可选上传资料 | 文件选择或拖放教材、课件、笔记；可逐文件移除 | 每个文件分别显示上传中、成功或失败 | 可不上传；失败文件可单独重试或移除，不清空目标和其他成功文件 | 回到首页草稿态 | 上传缓存不是 W / C / L；不得写 `L` |
| J1.3 提交课前草稿 | 唯一主按钮「开始上课」；提交中禁止重复点击 | 显示正在分析需求；按钮进入忙碌态 | 分析失败可原地重试；已填目标与上传结果保留 | 创建 `courseId`、自动进入生成预览（J2.0）；首页不再有追问或范围界面 | 迁移时创建当前 `C` 并写需求；不读其他 `C`，不建 `W` |
| J2.0 预览页按需课前追问 | 预览页内卡片逐题点选；按钮「继续」；可逐题或整体跳过 | 显示当前问题、已选项与剩余少量问题；不展示后台 Agent | 可逐题或整体跳过；请求失败保留已答，提供重试或跳过 | 回答或跳过写入本课需求；范围仍宽则到 J2.0b，否则开始生成大纲并到 J2.0c | 读本次输入与 `L`；同课恢复才可读当前 `C`；回答在生成开始后随需求归入 `C`，不直接写 `L` |
| J2.0b 预览页按需选择范围 | 知识树成功加载后用复选框确认，推荐项默认勾选；按钮「按所选范围备课」或「使用推荐范围」 | 加载成功显示层级、推荐项与当前选中范围；确认 / 提交显示进行中、成功或失败 | **首次加载失败且没有推荐范围**：可「重试」，或「跳过范围确认，按需求与合理默认备课」；**知识树已成功加载但确认 / 提交失败**：保留已选项与缓存推荐项，可重试提交或使用缓存推荐范围 | 成功后把最终范围（跳过时含合理默认）归入本课需求，开始生成大纲；不再出现第二个「开始上课」 | 失败恢复期间不建 `W`；开始生成时才写新课 `C` 的需求、课前回答与最终范围；不把课程内容或课前偏好立即写 `L` |
| J2.0c 生成大纲与教案 | 无需输入，观看骨架流式到达与教案设计进度 | 大纲骨架逐条可见；主 Agent 先确定并保存全课视觉方向，再设计节点；生成完成后教案只读可见 | 节点教案失败可降级为真实大纲骨架；视觉方向生成失败留在预览重试，不假装已确定风格；已保存风格不重做 | 教案与视觉方向就绪后逐段生成 HTML 内容，到 J2.1 | 读当前课程资料与 `C` 中的需求 / 范围；教案和视觉方向属生成 / 文档状态，不写 `W` / `L` |
| J2.1 逐段生成 | 无需输入即可观看进度；可点开正常生成或已完成的段，只读查看该段教案与已生成课堂材料 | 每段显示等待、生成中、完成或失败；点开后显示该段讲授设计，以及已生成的幻灯片缩略图 / 题面 / 互动页；生成中的段显示当前子步骤（内容或动作） | 页面 / 加载失败留在预览并提供重试；成功段保持完成；点开查看不改变生成状态 | 全部完成后停留在预览可进入态；存在失败则到 J2.2 | 读当前课程资料与 `C` 中的需求 / 范围；生成进度属生成 / 文档状态，不写 `W` / `L` |
| J2.2 重试失败段 | 仅失败段显示「重试该段」 | 只让该段回到生成中；其他成功段不变化 | 再次失败仍停在该段，可继续重试 | 全部段完成后回 J2.1 的可进入态 | 不新增学习证据；不改 `L`；不得重写成功段 |
| J2.3 进入课堂 | 全部就绪后显式点「进入课堂」 | 显示课堂加载状态 | 加载失败留在预览，可重试；不得自动跳转 | 成功后新建课堂 session 和 `W`，进入 J3.1 | 读当前 `C + L`，新建 `W`；不读旧 `W` |
| J3.1 同步讲授 | 听教师音频，看幻灯片 / 白板同步推进 | 当前节点、播放状态与教师动作可见；教师讲授文本以实时字幕呈现 | 音频或节点加载失败显示「重试当前节点」，失败不推进 | 只有教师 speech / action 均成功结束且控制器提交类型化幂等事件 `lesson.complete_node` 后，才到下一讲授或 J3.3；若它完成最后一个尚缺的必需动作，则唯一经 `completed → finalizing → J4.1` | 事件先更新 `W`，并立即把 `C.completedNode / C.progress` 持久化；该事件不生成 `EvidenceRecord`、不表示掌握；播放失败或仅播放到达不得写成已讲 / 已掌握 |
| J3.2 自然插话 | 通过麦克风直接说话，或在课堂问题框输入文字并发送；可用「换个说法 / 举个例子 / 给点提示」填入追问，也可选中 HTML 讲授文字作为可移除的引用；快捷填入和选文均不自动发送 | 草稿与引用可见；显式发送后老师确认收到、暂停原讲授、回答，并明确说明回到 `resumeNode`；学习者问题以字幕回显 | 识别失败提示重说；发送失败保留文字及当前页引用可重试；切页清除引用，连接期间节点或播放状态改变时不发送旧问题；保留 `resumeNode`，不丢主线 | 回答音频成功结束后回 J3.1 的原节点；等待检查作答时回原检查态；回放不提供这些提问交互 | 未发送的草稿与引用只在界面内存中，不写 `W / C / L`；显式插话及 `resumeNode` 写 `W`，未解决问题可归 `C`；原始对话不写 `L` |
| J3.3 检查点 | 按题型点选或输入，显式点「提交答案」 | 显示提交中、对错和教师反馈 | 判分失败保留答案并可重试；必要检查不能跳过并标成完成，学习者可暂停或暂时离开为未完成 | 判分成功后按结果再讲或进入下一节点；若最后一个必要检查已有有效 evidence 且它是最后尚缺的必需动作，则唯一经 `completed → finalizing → J4.1` | 一次提交只 append 一个 `EvidenceRecord` 并投影 `C`；幂等重试不得重复证据；不直接写 `L` |
| J3.4 暂停 | 点明确的「暂停」控件 | 音频、动作和进度停住，显示已暂停 | 暂停失败保持原播放态并提示重试，不推进节点 | 进入暂停态 | 暂停位置写 `W`；可恢复点快照写 `C`；不写证据 / `L` |
| J3.5 继续 | 暂停态点「继续」 | 显示恢复中，并从保存位置继续 | 恢复失败仍保持暂停，可重试 | 回 J3.1 或原检查态 | 读当前 `W`；必要时读 `C` 恢复点；不新增证据 |
| J3.6 重听已讲部分 | 在已讲范围选择重听 | 显示回放位置与“返回原位置” | 回放失败留在原位置；只能选择已讲部分 | 回放结束自动回到进入重听前的位置 | 回放位置写 `W`；不新增 `EvidenceRecord`，不重判 `GoalState`，不改 `L` |
| J3.7 暂时离开未完成课堂 | 点明确控件「暂时离开课堂」 | `saveAndLeaveSession` 显示保存中；课程始终标记未完成 | 保存失败留在课堂并显示重试；浏览器 / 标签卸载只允许 best-effort 保存，不算成功迁移，也不得销毁可重试状态 | 幂等保存成功后先写 `C` 恢复点，再销毁本次 `W`，最后回首页；下次走 J4.4 的「继续」 | `saveAndLeaveSession` 将可恢复点快照先持久化到 `C`，确认成功后销毁 `W`；必要检查未完成不得改成完成；不写 `L` |
| J3.8 完成归档（`finalizing`） | 最后一个必需动作完成后自动开始；失败时点「重试归档」 | 显示归档中；成功前不显示课后选择 | `finalizeSession` 失败停在 `finalizing`，保留 `W` 与待归档状态并显示重试；不得假装已保存或提前显示课后选择 | 唯一的幂等 `finalizeSession` 成功后销毁原课堂 `W`，进入 J4.1 | 归档 `W → C`；仅把合法 learner-only candidate 经 policy 写 `L`；两者成功后才销毁 `W` |
| J4.1 课后选择（finalization 已成功） | 无；等待选择「再听」或「离开」 | 显示唯一两个课后动作「再听」「离开」 | 页面显示失败可重新加载同一已归档课后选择；不得再次 finalization | 选择「再听」到 J4.2；选择「离开」到 J4.3 | 不读写 W / C / L；原课堂 `W` 已销毁 |
| J4.2 课后再听 | 在课后选择点「再听」；重听中点「暂停」「继续」或「结束重听」 | `replaySession` 显示从 `C` 加载的持久化已讲范围、重听位置与播放状态；完成课的已讲范围是全课 | 加载失败留在课后选择态并可重试；播放失败留在当前回放位置并可重试；不得调用 `finalizeSession` | 每次「再听」都新建独立 replay `W`；自然结束或显式「结束重听」后销毁该 replay `W` 并回课后选择态 | 只读同一 `C + L`，播放范围只取 `C`，不读旧 `W`；只写并最终销毁 replay `W`；不写 `C / L`，不新增 `EvidenceRecord`、不重判 `GoalState` |
| J4.3 课后离开 | finalization 已成功的课后选择态点「离开」 | 立即显示返回首页的导航反馈 | 导航失败仍留在课后选择态，可重试导航 | 只导航回首页，不再次保存、归档或销毁 | 不读写 W / C / L；此时原课堂 `W` 已由 `finalizeSession` 销毁 |
| J4.4 首页重开同课 | 点最近课堂卡片：尚未生成完成的课进入生成预览（J2.1）；生成完成后进入首页同课选择态；仅未完成课程可点「继续」，有持久化已讲范围即可点「再听」；重听中可暂停 / 继续 / 结束 | 备课中的课标明备课进度入口；生成完成后显示未完成 / 完成状态；「继续」显示教学恢复加载；「再听」显示 `C` 中已讲范围、回放位置与播放状态（完成课为全课） | 备课中的课加载失败留在预览并提供重试，不得进入同课选择态或课堂；「继续」或「再听」加载失败都留在首页同课选择态并可重试或返回首页；回放播放失败留在当前回放位置并可重试；不得创建新课程 | 尚未 `generationComplete` 的课回到 J2.1 查看并继续备课；「继续」只恢复未完成教学：读 `C + L`、新建 teaching `W` 后到未完成位置；「再听」每次新建独立 replay `W`，自然结束或「结束重听」后销毁它并回首页同课选择态 | 回预览不新建 `W`，不改 `C / L`；「继续」读该课程 `C + L` 并新建 teaching `W`；「再听」只以 `C` 的持久化已讲范围为播放内容，可读同一 `L`，新建并最终销毁 replay `W`；两者绝不恢复旧 `W`；replay 不 finalize、不写 `C / L`、不新增 `EvidenceRecord`、不重判 `GoalState` |
| J5.1 开始另一课程 | 回首页填写新目标，按 J1 操作 | 与 J1 相同 | 与 J1 相同 | 创建新的 `courseId` 后进入 J2 | 只读 `L`；不得读取或注入任何其他课程 `C` |
| S1 设置 | 遮罩密钥输入、联网开关（默认关）、显式「保存」 | 每个字段分别显示保存中、成功或失败 | 失败字段可单独修改并重试；不影响现有课程 | 保存后留在设置或返回原页面 | 只读写配置存储；绝不读写 W / C / L |

## J1 说明要学什么

学习者先填写主题 / 目标并可选上传资料，然后只按一次「开始上课」。该按钮提交课前草稿并直接进入生成预览；追问与范围确认都在预览页内、生成教案之前完成，首页不出现第二个同名按钮，也没有追问界面。

“学习程度”始终相对于本课程或本主题判断，属于本课课前判断或同课程记忆，不写成跨课程全局知识标签。本次明确表达优先于历史记忆，并立即影响本课；首页草稿只在提交时进入生成会话，课前回答在生成开始时写当前 `C`，不立即写 `L`。只有课堂 `finalizeSession` 时，明确表达为「长期 / 通常」偏好，或已有跨多课证据达到 policy 门槛的 learner-only candidate，才可写 `L`。所有台后 worker 都不以第二个身份出现在界面。

完成：课前草稿仅提交一次；提交后自动进入生成预览。

## J2 等课备好

进入预览页后、生成教案之前，Agent 老师只对**会改变本课设计、且本次输入与适用记忆不能可靠回答**的事项追问。追问可包括本主题程度、目标、教学方法、讲解深度、节奏与互动方式；用页面内卡片逐题点选，可以逐题或整体跳过。需求太宽时再显示知识树复选框，推荐项默认勾选；学习者确认所选范围或直接使用推荐范围。追问与范围确认的答案立即作为大纲与教案生成的输入。

知识树首次加载失败时还不存在可用推荐范围：学习者可以重试，或明确跳过范围确认，让系统按需求与合理默认备课。知识树一旦成功加载，已选项与推荐项即缓存；之后确认 / 提交失败不得清空它们，学习者可以重试或改用缓存推荐范围。

预览页随后生成教案，并按教案逐段显示等待、生成中、完成和失败。新课每页采用模型生成 HTML，主 Agent 的全课视觉方向先于逐页生成并随教案保存；各页自由设计，但共享该方向。正常生成或已完成的段可点开只读查看该段教案与真实 HTML 材料；失败只重试该段，成功段和视觉方向不重做。从首页打开尚未生成完成的课也回到这一预览，而不是同课选择态。全部就绪后仍停留在预览，由学习者显式点「进入课堂」；课堂加载失败也留在预览重试。

完成：必要信息已经回答、由适用记忆补足或跳过；范围加载与提交失败均按上述两类恢复；生成开始时把需求、课前回答与最终范围归入 `C`。所有段已完成，学习者明确进入课堂并新建 `W`。预览过程中没有同学发言、圆桌讨论或材料编辑。

## J3 上课

J3.2a 口头问答：教案可在讲授节点预设一个口头问题，绑定到中段讲稿句之后。老师问完等待学习者直接说话或显式提交文字；根据真实回答反馈并最多追问两次，再回原讲稿。等待时可要提示或选择继续讲解；沉默不自动推进、不当作答错，识别失败可重说，反馈失败保留本轮回答并可重试。暂停 / 切页 / 离开取消当次问答，继续从原讲稿句重新进入，不静默跳过。口头问答不替代必要检查，不判分、不写掌握证据；replay 只播放讲稿，不发起问答。没有 HTML 视觉方向的课不得打开，因此也不进入口头问答。

课堂上只有一位教师（Airi + 全双工语音）。学习者显式开始讲授时建立语音连接，教师按节点讲稿发声；音频未配置、连接失败或播放失败时留在当前节点，不以阅读计时器代替发声。教师音频与幻灯片 / 白板同步；当前节点成功完成后自动进入下一节点，不依赖旧播放器的自动播放偏好。学习者通过麦克风或课堂文字问题框插话；教师先确认和回答，再明确返回 `resumeNode`，文字输入不另开聊天主线。检查点按题型点选或输入后显式提交，教师用语音反馈并对错误补充解释，再继续教学；反馈失败保留本次结果和重试入口，不重复判分或证据，不提前进入课后。

暂停、继续、重听和节点重试都是明确控件。失败不推进；重听只覆盖已讲部分并回到原位置，不新增证据或重判掌握。未完成课堂只能通过明确的「暂时离开课堂」触发幂等 `saveAndLeaveSession`；成功顺序固定为先写 `C` 恢复点、再销毁 `W`、最后回首页，失败留在课堂重试。关闭浏览器或标签只做 best-effort 保存，不能算作成功离开迁移。必要检查不能跳过后仍把课程标为完成，学习者只能把课程保持为未完成后暂停或暂时离开。

节点讲授完成的权威事实是控制器提交的类型化幂等事件 `lesson.complete_node`：只有教师 speech / action 都成功结束才可提交。事件更新 `W` 并立即持久化 `C.completedNode / C.progress`，但不生成 `EvidenceRecord`、不代表掌握。最后一个必需讲授节点完成，或最后一个必要检查取得有效 evidence，且由此补齐最后尚缺的必需动作时，课堂才唯一迁移 `completed → finalizing → J4.1`。

检查完成与掌握结论分开：成功提交的客观评分、以及保留模型来源的参考评分均可证明检查已做；模型评分仍保持 `pending_review`，不冒充 accepted 掌握证据，不引入人类教师审核入口。

当前明确表达优先，其次是 `W`、当前 `C`，最后才是 `L`；当前表达立即影响本课但不在课中直接写 `L`，其他课程知识内容不进入本课。

完成：每个节点确实讲过或检查过；讲授完成事件及时持久化课程进度；播放到达、播放失败与判分重试都没有伪造“已讲 / 已掌握”或重复证据。未完成离开与课堂完成各自只有上述唯一迁移，台上没有第二张嘴。

## J4 再听、继续同课或离开

补齐最后一个必需动作后自动进入 `finalizing`。唯一的幂等 `finalizeSession` 负责归档 `W → C`、将合法 learner-only candidate 经 policy 写 `L`；全部成功后才销毁原课堂 `W` 并显示「再听」「离开」。失败停在 `finalizing`、保留 `W` 和待归档状态，并显示重试。

课后与首页同课选择的「再听」共用同一个独立 `replaySession` 生命周期：每次都读取同一课程 `C + L`、绝不恢复旧 `W`，并新建 replay `W`；播放内容严格取 `C` 中持久化的已讲范围，完成课即全课。重听允许显式暂停 / 继续 /「结束重听」；加载失败留在发起入口的选择态，播放失败留在当前回放位置并可重试。自然结束或「结束重听」只销毁 replay `W`：课后入口回课后选择态，首页入口回首页同课选择态。replay 不走 `finalizeSession`，不写 `C / L`，不新增 `EvidenceRecord`，也不重判 `GoalState`。「离开」只在 finalization 已成功后导航回首页，不再次保存或销毁。

首页最近课堂卡片打开同课后进入明确选择态。「继续」只对未完成课程可用，只读同一 `C + L` 并新建 teaching `W`，从持久化未完成位置恢复教学；它绝不恢复旧 `W`，也不用于已完成课程。「再听」则始终进入上述独立 replay 生命周期。两种加载失败都留在首页同课选择态，可重试或返回首页，绝不因此创建新课程。

完成：学习者能以新 teaching `W` 继续未完成同课；课后与首页都用同一独立 replay 生命周期播放 `C` 中已讲范围，并返回各自选择态。finalization、暂时离开和 replay 的 `W` 销毁顺序互不混用，途中没有进入编辑器。

## J5 开始另一课程

学习者从首页提出另一个目标时重新走 J1。新课只读 `L` 中对学习者本人的稳定了解，例如语言、教学方法、节奏、互动 / 反馈偏好、无障碍需要和稳定约束；不读取或注入其他课程的课程名、知识点、题答、分数、掌握结论、课程摘要或原始对话。

平台“学得越多，越了解学习者”只表示 learner-only 判断可随证据更新。一次行为不能永久定型；当前明确表达可以覆盖旧判断。“跨课程”不推出账号同步、设备合并或跨设备档案。

完成：新课复用适用偏好但重新判断本主题程度，输入上下文没有其他课程 `C`。

## 不存在的路径

这些路径不准写进手册，也不准做成默认入口：

- 人类教师改课、审阅、把关
- 可视化编辑器 / Pro 模式 / Agent 改某一页
- 首页「联网 / 深度交互 / 职教」三条产品线
- AI 同学、助教、圆桌轮流发言
- 多课时课程规划、摄像头观察、BKT / FSRS、跨设备档案
- 把其他课程内容、题答或掌握结论当作新课记忆注入
- 将课前确认做成必填长问卷，或重复询问本次输入与适用记忆已经可靠回答的问题
- 把播放到达、加载失败、跳过必要检查或判分重试记录成已讲、已掌握或第二条证据
- 用关闭 / 返回代替「暂时离开课堂」的成功迁移，或在保存 `C` 失败前销毁 `W`
- 让 replay 再次 finalization、写 C / L、生成证据或重判掌握，或让首页 / 课后 replay 结束后返回错误的选择态
- 用「继续」打开已完成课程、进入 replay 或恢复旧 `W`，或让设置读写学习记忆
