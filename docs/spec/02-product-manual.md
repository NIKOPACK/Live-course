# 产品手册

规定学习者在每个画面**可以做什么、看到什么反馈、失败后怎样恢复、完成后去哪里**。画面上未写出的能力，对学习者不存在。

依据：[01-user-journeys.md](01-user-journeys.md) 的逐步交互契约。

## 首页 `/`

### 首屏展示

- 品牌、学习目标输入区与一位 AI 老师构成同一课堂场景；首页仍是直接开始学习的入口，不另设宣传页或第二个启动按钮
- 文案突出同步讲解、板书、随时插话与答疑后继续教学，不承诺仅凭听课即已掌握
- 桌面可以展示明确标注的固定板书示意，并说明正式内容将在备课后生成；示意不读取课程记忆，不代表正在讲授、已经备课或真实学习进度
- 窄屏保留轻量老师海报，不下载 3D 模型；桌面先显示同一海报，空闲时再加载活体形象，加载或失败不阻塞填写目标
- 示例目标只填入并聚焦原输入框，不自动提交；最近课堂为空时使用简短提示，不伪造课程或学习记录
- 入场、聚焦与提交反馈不延迟输入或导航；减少动态效果偏好下取消装饰动效，首页老师保持静态海报

### 填写目标与上传

可以：

- 在一个文本框里写主题或目标
- 通过文件选择或拖放，可选上传教材、课件、笔记
- 查看每个文件各自的上传中、成功或失败状态；失败文件可单独重试或移除
- 在最近课堂卡片上打开同一课程：尚未生成完成的课进入生成预览查看备课进度；生成完成后进入同课选择态，仅未完成课程可选「继续」，有持久化已讲范围即可选「再听」
- 看到卡片左侧的课程封面；封面尚未生成或生成失败时看到占位图标，仍可打开该课
- 在最近课堂卡片上删除一门自己生成的课（含尚未生成完成的课）；删除前须确认。展示课不可删
- 按唯一主按钮「开始上课」提交课前草稿

交互反馈与恢复：

- 目标为空时「开始上课」保持禁用；行内必填提示由目标框 touched / blur 或键盘提交尝试触发，不依赖点击 disabled 按钮
- 上传失败不清空目标，也不影响其他已成功文件
- 提交后按钮进入忙碌态并禁止重复提交；分析失败时保留草稿与上传结果，原地提供重试
- 尚未生成完成的课点开后进入生成预览，不进入同课选择态，也不创建课堂 `W`
- 「继续」只恢复未完成教学：读取同一课程 `C + L`，新建 teaching `W` 并到持久化的未完成位置；不恢复旧 `W`，也不用于已完成课程或尚未生成完成的课
- 首页「再听」与课后「再听」共用独立 `replaySession`：每次新建 replay `W`，播放 `C` 中持久化的已讲范围（完成课为全课），支持暂停 / 继续 /「结束重听」
- 「继续」或「再听」加载失败都留在首页同课选择态，可重试或返回首页；不得恢复旧 `W` 或因此新建课程
- replay 播放失败时留在当前回放位置并可重试；自然结束或点「结束重听」后销毁 replay `W`，回首页同课选择态
- replay 不调用 `finalizeSession`，不写 `C / L`，不新增 `EvidenceRecord`，不重判 `GoalState`
- 封面生成失败或未配置图片 provider 时卡片保留占位，不挡打开课程，也不出现重做封面入口
- 「删除」是独立控件，不占用打开课程的点击，也不占用同课选择对话框的「继续 / 再听」。一点确认：若该课的 `CourseEntryDialog` 开着则关掉，并作废进行中的 `openCourseEntry`。确认后才删除；取消则卡片与对话框不动。删除中禁止重复提交。失败时确认框保持打开，显示失败文案，破坏性按钮可再点重试。成功后该卡从最近课堂列表去掉（其余卡片仍在，不闪整架加载）；若没有剩余课堂，显示已有空架提示。不导航、不新建课程、不提供撤销
- 删除备课中的课时，成功后丢掉该课可恢复的 generation session，预览不得再续写已删 `stageId`。这 **不是** 改「从预览返回首页仍保留 generation session」——那条继续有效
- 删除进行中或已成功的 id，同课选择的继续 / 再听不再导航；成功后 `?course=` 指向该 id 不得再打开对话框

不可以：

- 在首页打开「联网 / 深度交互 / 职教」三种产品开关
- 选择同学、助教或圆桌人数
- 进入编辑器或导入一条「给老师改」的流程
- 在首页追问或展示范围勾选（课前确认只在生成预览页进行）
- 被迫完成长问卷，或被重复询问已经可靠回答的信息
- 因开始新课而看到其他课程的名称、知识点、题答、分数、掌握结论、课程摘要或原始对话
- 看到多个 Agent 角色或工作流面板
- 不经确认删除课程
- 从回收站或撤销提示恢复已删课程
- 在生成预览、课堂或设置里删除单门课
- 删除展示课 `fourier-intro`

完成：草稿只提交一次；页面自动进入生成预览。

## 生成预览 `/generation-preview`

### 按需课前确认（生成教案之前）

进入预览页后，若确有缺失信息，页面内依次显示：

1. **课前问题卡片**：一次一题，点选答案；问题可涉及本主题程度、目标、教学方法、讲解深度、节奏与互动方式。按钮为「继续」，可逐题或整体跳过。
2. **范围知识树**：仅当范围太宽时出现；使用复选框，推荐项默认勾选。主动作是「按所选范围备课」，也可点「使用推荐范围」。

交互反馈与恢复：

- 只问会改变本课设计、且本次输入与适用记忆不能可靠回答的问题
- 卡片显示当前选择和剩余的少量问题，不展示后台 Agent 身份
- 课前问题请求失败时保留已答内容，提供重试或跳过
- 知识树首次加载失败且尚无推荐范围时，提供「重试」或「跳过范围确认，按需求与合理默认备课」
- 知识树已成功加载后缓存已选项与推荐项；确认 / 提交失败时保留两者，提供重试或「使用缓存推荐范围」
- 草稿、课前回答与当前明确偏好只影响本课，在生成开始时写入当前课程；不会当场变成跨课程偏好。当前表达在本课立即优先，只有 finalization 时符合长期 / 通常表达或多课证据 policy 门槛的 learner-only candidate 才能跨课保留
- 确认结束（或无需确认）后自动开始生成教案，不再出现第二个「开始上课」
- 追问与范围确认期间，页面其余部分保持备课进行中的视觉状态

### 生成教案与逐段内容

每一页（讲授、检查与互动）都由模型制作 HTML。主 Agent 先确定本课统一的视觉方向，再让各页自由设计布局、图解、动画与交互，不套固定幻灯片元素或 widget 模板。视觉方向随课保存，失败段重试不重新决定风格。没有 HTML 视觉方向的课不能打开，也不回退成幻灯片或 widget。

可以：

- 看每个教案段讲什么，并在教案就绪后只读查看整份教案
- 看每段独立的「等待 / 生成中 / 完成 / 失败」状态
- 点开正常生成或已完成的段，只读查看该段课堂画面与教案；生成中先看到预留画板与当前子步骤，完成后看到真实 HTML / 题面 / 互动页
- 只在失败段点「重试该段」
- 全部就绪后显式点「进入课堂」

交互反馈与恢复：

- 教案生成期间展示等待反馈；教案生成失败降级为只按大纲继续，不阻塞流程
- 点开查看是只读的：不改变该段状态，也不重做成功段
- 生成中的段点开后，课堂画面在前：预留画板承载当前子步骤（正在生成页面内容或编排讲解动作）；讲什么用列表扫读，怎么讲 / 例子 / 预设问答分区显示，不与画面抢同一层级
- 重试失败段时，只有该段回到生成中；成功段保持完成，不重做
- 页面或数据加载失败时留在预览，显示重试；不得清空已经成功的段
- 未全部就绪时「进入课堂」不可用
- 全部就绪后也不得自动跳进课堂
- 点击「进入课堂」后显示加载状态；加载失败仍留在预览并可重试

不可以：

- 在预览里和 AI 同学讨论
- 改幻灯片、改测验、审阅或编辑大纲 / 教案、重做成功段或让 Agent 重做某一页
- 把预览当成第二种产品

完成：课前确认已回答或按对应失败分支跳过；所有段生成成功，学习者显式进入课堂，没有改过材料。

## 课堂 `/classroom/:id`

### 老师区

- 桌面右侧按老师身份与状态、形象、语音控制和提问区排列，不增加独立聊天栏或第二个开始讲授入口。窄屏改为底部紧凑老师区；长问答与引用在操作区内滚动，不挤掉课堂材料
- 语音未连接时提供带文字的连接按钮；连接后直接显示麦克风开关状态，打断与断开收进「更多语音操作」。连接只建立原语音会话，不代表开始或完成讲授
- 提问框支持多行输入与有上限的自动增高；Enter 显式发送、Shift+Enter 换行，中文输入法确认不发送。快捷追问仍仅填入草稿；发送中锁定、失败保留问题与引用，暂停时说明继续后可提问
- 状态变化、输入聚焦与按钮按下有轻量反馈；减少动态效果偏好下取消非必要动效。语音状态与错误始终用文字表达，不只依赖颜色

### 讲授与节点失败

HTML 是课堂材料的表现层，不是另一位教师或独立课程。页内脚本只在隔离沙箱中运行；测验必须显式提交，仍由课堂的判分、反馈与证据链处理。页内动画结束、页面自行声称完成均不能推进教学或写掌握状态。

HTML 检查页运行失败时保留答案，可「重试页面」，或明确选择「基础题目视图」继续同一次作答；正常页面不提供格式切换。这是故障恢复，不会自动重答、重判或生成新证据。

可以：

- 听教师用全双工语音讲授，同时看当前幻灯片、白板或互动页
- 看教师讲授的实时字幕；插话时看到自己话语的识别回显
- 看到当前节点和播放 / 暂停 / 加载状态
- 当前音频或节点加载失败时点「重试当前节点」
- 点「开始讲授」建立语音连接并从当前节点开始；完成讲授后由老师继续下一节点，在检查点等待作答

交互反馈与恢复：

- 音频、画面与教师动作同步推进
- HTML 讲授按讲解段落切换当前重点；高亮保持到下一重点，推导步骤在讲到时显露，不依赖页面计时器自动播放。页面尚未就绪时等待，动作投递或目标元素失败时停在当前动作并可重试，不让语音和画面脱节
- 字幕随语音逐句更新，只是讲授的可见反馈：不持久化、不产生证据、不改变掌握，也不构成第二条课程主线；字幕事件不可达时不显示，不影响讲授
- 加载失败显示在当前节点，不自动前进
- 语音未配置、连接或发声失败同样留在当前节点；不会用静音阅读时间冒充讲授，连接成功也不等于节点完成
- 只有教师 speech / action 都成功结束且课堂控制器提交幂等 `lesson.complete_node`，讲授节点才显示完成；它立即持久化课程 completedNode / progress，但不生成作答证据、不表示掌握
- 最后一个必需讲授节点完成，或最后一个必要检查已有有效 evidence 并补齐最后尚缺动作后，课堂只按 `completed → finalizing` 进入归档；播放到达和播放失败都不等于已讲或已掌握

### 插话

可以：

- 通过麦克风自然说话插入问题
- 在课堂问题框输入文字并发送；与麦克风共用同一个老师和插话恢复点，不打开独立聊天栏
- 点「换个说法」「举个例子」「给点提示」准备追问；只填入或追加到问题框，不覆盖已写文字，不自动打断老师
- 在带教师桥的 HTML 讲授页用鼠标、触摸或键盘选中文字，问题框显示最多 500 字的引用；可移除引用，再显式发送自己的问题。选文不暂停教学、不代答题目、不产生学习证据
- 听老师直接回应问题，而不是复述问题；需要时简短承接，再按刚才讲到的内容自然接回讲解，不固定念“回到原节点”或内部编号

交互反馈与恢复：

- 教师开始回答时暂停原讲授并保留返回点
- 语音识别失败时提示重说，不丢返回点、不跳到下一节点
- 文字发送失败保留输入，可原地重试；检查点等待作答时也可以提问，答复后仍回原题
- 引用和快捷追问共用上述发送与重试；发送中不可重复提交，失败保留问题及当前页引用。切页、离开或进入回放清除引用；连接期间若教学节点或可提问状态改变，不向新节点发送旧问题，提示确认后重试。隐藏 iframe、预览和回放不能注入引用或发起提问
- 回答音频实际结束后回到原节点的未完成短语音块；本次播放已完整听完的块不重播，不把插话变成第二条课程主线。问题字幕只作输入回显，回答后不重新覆盖教师字幕

### 讲授中的口头问答

- 老师在教案预设位置提出问题后停住讲稿；显示当前问题、等待回答 / 正在聆听 / 老师回应等状态。可直接用麦克风回答，也可输入文字并显式发送；麦克风不可用时使用文字，不以沉默当答案
- 回应针对真实回答给出解释、提示或进一步的问题；最多两次追问，第三次回答讲评结束后继续原讲稿，不无限盘问
- 等待时可点「给点提示」或「继续讲解」；提示不消耗回答轮次，继续讲解不冒充答对或掌握
- 识别失败保留问题并提示重说；回应失败保留本轮回答，可「重试问答」，不重复增加轮次。等待没有自动超时完成
- 暂停、切页或离开取消当次问答并保留讲稿游标；继续时重新讲当前句并进入该提问。回放不要求再次作答。口头问答不会提交正式检查、创建 EvidenceRecord 或改变掌握状态

### 检查

可以：

- 按题型点选选项或输入答案
- 显式点「提交答案」
- 查看提交中、对错与教师反馈

交互反馈与恢复：

- 判分失败时保留答案，学习者可重试提交
- 同一次提交的网络 / 判分重试不得显示成两次作答
- 老师用语音说明检查结果；答错时根据题目解释补讲，再继续下一节点。反馈失败保留已评分结果并可重试，不重复证据；最后一个检查的反馈完成前不显示课后选择
- 简答题的模型评分标为参考评分；完成检查不等于证明掌握，不要求学习者等待一个不存在的人类教师审核入口
- 已评分但尚未完成讲评的检查，在暂时离开后继续上课时复用原答案、评分和提交标识；在新的课堂工作记忆中恢复检查状态，再讲评并提交，不重复判分或新增重复证据
- 必要检查不可跳过后仍将课程显示为完成；学习者可以暂停或点「暂时离开课堂」，但课程保持未完成

### 暂停、继续、重听与暂时离开

可以：

- 点明确的「暂停」「继续」控件
- 查看当前章节 / 总章节及已完成章节数；点「上一章节」「下一章节」切换相邻教案节点，首尾按钮禁用，切换后等待显式开始讲授
- 只选择已经讲过的部分重听
- 未完成时点明确的「暂时离开课堂」

交互反馈与恢复：

- 暂停失败时保持原播放状态并提示重试，不推进节点
- 继续失败时保持暂停，可再次重试
- 讲稿每个短语音块开始前保存章节、动作和块位置；从首页继续同课时重建该位置之前的必要画面，再从保存块开始，最多重讲退出时的当前块。播放位置与已完成进度独立，跳到后面不算学完前面
- 切换前冻结旧讲授并保存；保存或导航失败显示错误，不把失败当切换成功。切换中禁止重复点击、播放和离开；插话、重听、检查讲评和语音连接期间暂不允许切换
- 重听时显示回放位置；结束后回到开始重听前的位置
- 重听失败时留在原位置
- 重听不新增作答记录、不重新判分或改变掌握状态
- 点「暂时离开课堂」后显示保存中；等待当前位置保存成功，再经幂等离开命令持久化课程恢复点、销毁临时课堂状态并回首页
- 暂时离开保存失败时留在课堂并可重试；浏览器 / 标签卸载只有 best-effort 保存，不算成功离开，也不能替代该控件

不可以：

- 听到第二位 Agent
- 切换到编辑态或 Pro 模式
- 改页、增删场景或重生成动作
- 看到给人类教师用的掌握度工作台
- 把必要检查静默跳过并完成课程

完成：一堂课靠听、插话、提交检查走完；失败不会推进；途中没有改课入口。

## 课后

最后一个必需动作完成后，课堂自动进入 `finalizing`。唯一、幂等的 `finalizeSession` 先归档课堂临时状态到课程记忆，再让符合 policy 的 learner-only candidate 写入跨课程记忆；全部成功后才销毁原课堂临时状态，并显示：

- **「再听」**：与首页同课「再听」共用独立 `replaySession` 生命周期；每次新建 replay `W`，播放 `C` 中持久化的已讲范围，完成课即全课，不恢复上次临时会话状态
- **「离开」**：只导航回首页，不再次保存、归档或销毁

交互反馈与恢复：

- finalization 显示归档中；失败停在 `finalizing`，保留待归档课堂状态并显示「重试归档」，不得先进入课后选择
- 再听加载失败留在课后选择态并可重试；重听中允许显式暂停 / 继续 /「结束重听」
- replay 播放失败留在当前回放位置并可重试
- 重听自然结束或点「结束重听」后销毁本次 replay `W` 并回课后选择态；首页发起的同一生命周期则回首页同课选择态
- replay 不调用 `finalizeSession`，不写 `C / L`，不新增 `EvidenceRecord`，不重判 `GoalState`
- 「离开」导航失败仍留在已归档的课后选择，可重试导航
- 从首页最近课堂进入时，尚未生成完成的课回到生成预览；只有生成完成后的未完成课程可「继续」教学；有持久化已讲范围即可「再听」；同课选择态加载失败留在首页选择态，可重试或返回

不可以：

- 改某一页或让 Agent 重做一段
- 导出 PPT / 视频给老师审阅
- 把课交给另一个教师账号把关
- 因恢复失败创建一门重复课程
- 在课后「离开」时再次执行保存 / 销毁，或把 replay 当成新学习证据

完成：同课可以继续；完成课可用独立 replay 生命周期再听，或在 finalization 已成功后离开。新课不得带入其他课程学习内容。

## 设置

可以：

- 在遮罩输入框中配置上课所需的模型与语音密钥
- 用联网开关可选打开检索；默认关闭
- 显式点「保存」
- 查看每个字段分别的保存中、成功或失败状态
- 修改失败字段后单独重试；失败不影响已有课程

不可以：

- 在设置里编辑学习者画像、课程记忆或课堂记忆
- 把设置做成本地模型生态、ComfyUI 工作流、语言包卖点或第二条产品
- 增加账号同步、设备合并或跨设备档案入口

设置只写配置存储，不会产生学习证据或改变学习者记忆。

完成：字段成功保存，或失败字段仍可重试；关闭设置后回到原页面和原课程状态。
