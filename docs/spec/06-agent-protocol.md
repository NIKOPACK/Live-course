# Agent 协议

对照规格开发。父代理不把本目录一次读进窗口。

依据：[00-index.md](00-index.md)。

## 每轮怎么拆

一次只做 [05-development-plan.md](05-development-plan.md) 里的一期（或该期的一个缝）。固定三个 subagent：

1. **spec-reader**
   只读本轮需要的规格章节（通常是 `01` 对应步骤 + `02` 相关画面 + `04` 对应缝 + `05` 该期）。
   交回：逐步摘录六列契约（步骤 / 状态、输入、可见反馈、跳过 / 失败恢复、终态迁移、W / C / L）、允许改的文件、验收和禁止事项。不改代码。

2. **implementer**
   只改列出的文件。提交说明引用 `docs/spec/…` 的章节标题，并逐步说明六列契约落在哪个状态机 / 控件 / 事件。不得只实现 happy path，不扩 scope。

3. **tester**
   按该期验收跑测试，或按手册逐步核对。每一步分别回报成功、允许时的跳过、失败恢复、终态和 W / C / L 正负读写。只回报缺口，不顺手加功能。

父代理综合 tester 结果：未过则只开下一轮 implementer，仍引用同一规格章节。

## 硬规则

- 没有规格章节的功能不准做。
- 规格与代码冲突：先改规格，再改代码。
- S0–S1 不新增领域模块。
- 圆桌目录先抽语音叠层，再去同学轮转；禁止整目录直接删除。
- 新库必须先写进 `04-detailed-design` 的参考表。
- 改记忆必须保持 session / learner+course / learner 三种作用域；tester 必须包含「新课不含其他课程内容」的负向泄漏用例，不能只验证正向召回。
- 每个台前步骤必须能对上 `01` 六列契约；加载、识别、判分、生成和保存失败必须留在可恢复状态，UI 到达或播放到达不能冒充学习证据。
- tester 必须区分范围失败：首次知识树加载失败且无推荐缓存，只能重试或按需求与合理默认跳过；树已加载后的确认 / 提交失败必须保留已选与缓存推荐项。空目标测试必须用 touched / blur 或键盘提交尝试触发行内提示，不能依赖 disabled click。
- tester 必须验证 A2 才新写的 `lesson.complete_node` 是权威、类型化、幂等事件：speech / action 未全部成功、媒体播放到达或加载回调都不能提交；成功后 W 更新且 C.completedNode / progress 立即持久化，但不产 evidence、不代表掌握。
- 未完成离开负测必须从明确「暂时离开课堂」进入 `saveAndLeaveSession`：保存 C 失败时仍留课堂且 W 未销毁；成功严格按 C → 销毁 W → 首页。关闭 / 返回 / 浏览器 unload 只能观测 best-effort，禁止断言为成功迁移。
- finalization / replay 负测必须分别证明：只有最后必需动作能触发 `completed → finalizing`；`finalizeSession` 失败保留 W 并停在 finalizing、幂等重试不重复归档，成功后才销毁 W；J4.3「离开」只导航；首页同课与课后「再听」共用 `replaySession`，每次独立新建 / 销毁 replay W，播放范围只取 C 中持久化已讲范围（完成课为全课），且不 finalize、不写 C/L、不新增 `EvidenceRecord`、不重判 `GoalState`。
- replay 恢复负测必须分别覆盖两个入口：加载失败留在发起入口的选择态且不恢复旧 W；播放失败保留当前回放位置可重试；暂停 / 继续不改 C/L；自然结束与「结束重听」销毁 replay W，首页入口回首页同课选择态，课后入口回课后选择态。
- 记忆负测必须证明 J1 草稿 / 课前答案生成前不写 C/L、生成开始只写 C；当前表达立即影响本课但不直接写 L；只有 finalization 时长期 / 通常显式偏好或跨多课证据达到 policy 门槛的 candidate 才写 L。
- 交互负测还至少包含：首页同课「继续」仅可恢复未完成教学，读 C+L 并新建 teaching W，已完成课不可继续，加载失败留首页同课选择态；继续与再听都不恢复旧 W 或创建新课程；设置和普通草稿不写 W / C / L；课中重听、首页 / 课后 replay、媒体 / 分段重试不产生 `EvidenceRecord`；判分重试同一提交只产生一个证据；必要检查无 evidence 时不能完成。

## 指针（复制到任务说明里）

- 改课堂主路径：读 `01` J3 对应六列 + `02` 课堂节 + `04` §1
- 改名册或画像：读 `04` §2 + `05` S1
- 改首页：读 `01` J1 与 J4.5 对应六列 + `02` 首页节 + `04` §3
- 改首页删除：读 `01` J4.5 六列 + `02` 首页节 + `04` §3 / §6 + `05` A7
- 改课前追问：读 `01` J1 + `02` 首页 + `04` §7 + `05` A3
- 改记忆 / 学习者画像：读 `01` J1/J4/J5 + `03`「记忆作用域」+ `04` §6 + `05` A6；测试至少覆盖同课重开、不同课新开、跨课负向泄漏、多课证据更新画像
- 藏编辑器：读 `02` 课堂 / 课后 + `04` §4
- 做 S0：读 `05` S0
- 做加法：先确认 `04` 已有「才新写」条目，再读 `05` 对应 A 期

## 完成标准

一轮结束时具备：规格引用、改动文件未超出 spec-reader 清单、实现与测试都逐步引用六列交互契约、tester 对成功 / 跳过 / 失败恢复 / 终态 / W-C-L 正负读写逐条表态。缺一项则这轮未完成。
